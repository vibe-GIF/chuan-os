## 2. A10 完整建制（定稿）

### 一、治理与领导层（顶层）

| 岗位 | 职责 |
|---|---|
| 家办 CEO / 总监 | 家族关系、整体运营、重大顾问协调，直接向富豪本人汇报 |
| COO 首席运营官 | 流程/制度/技术/供应商/服务交付，把委任变成操作系统 |
| 治理层 | 家族委员会、投资委员会、董事会（含家庭成员治理角色） |

### 二、财富与投资条线（核心）

| 岗位 | 职责 |
|---|---|
| CIO 首席投资官 | 投资政策、资产配置、经理选择、组合监控、投委会材料 |
| 投研团队 | 公共市场（股/债/对冲/SMA）+ 私募（PE/VC/信贷）+ 不动产，尽调、业绩跟踪 |
| 交易/分析岗 | 交易执行、估值、再平衡、风控监控 |

### 三、财务/法务/税务条线

| 岗位 | 职责 |
|---|---|
| CFO 首席财务官 | 会计、资金、现金流、合并报表、预算、内控（家办最重要运营岗）|
| 财务/会计岗 | 日常记账、对账、账单支付、资金管理 |
| 总法律顾问 | 股权、婚姻、继承、诉讼、合规、治理文件 |
| 税务总监 | 税务筹划、跨境、申报、信托/实体税务 |
| 合规/风控官 | 监管合规、防舞弊、职责分离 |

### 四、信托/传承/慈善条线

| 岗位 | 职责 |
|---|---|
| 信托/遗产管理 | 家族信托、持股平台、继承架构、申报义务 |
| 下一代教育官 | 领导力培养、财务素养、代际过渡 |
| 慈善官 | 基金会、捐赠、影响力评估 |

### 五、家族生活/礼宾条线

| 岗位 | 职责 |
|---|---|
| 生活大管家 | 多房产/别墅/物业/收藏品/家政人员统筹 |
| 贴身助理团队 | 2-3 人轮班，行程/差旅/宴会/医疗预约 |
| 礼宾/生活方式经理 | 旅行、活动、日程 |
| 安保团队 | 安全主管+保镖，风险评估、住所安防 |
| 技术总监 / IT | 网络安全、数据管理、报告架构 |
| 专属医疗顾问 | 三甲绿通、体检、海外就医 |
| 艺术/收藏顾问 | 字画、奢侈品收藏打理 |

### 六、底座系统（制度层，非岗位）

| 系统 | 内容 | 作用 |
|---|---|---|
| 系统①资产防火墙 | 家族信托、持股平台、保险、家企隔离 | 对抗债务/婚变/诉讼/分割 |
| 系统②人脉资源池 | 顾问/圈层/合作方通讯录 | 按需调动医生/律所/投行 |

## 3. 关键事实基准

- 完整 SFO 通常需 **$1 亿+** 可投资产才经济合理；$250M+ 规模中位 **6-9 人**全职（FOX 2023）
- **公私严格分离**：公司财务/法务 ≠ 家族财务/法务，家办只管家与家族的钱
- **合规红线**：SFO 绝不对外接受第三方资金（香港 SFC 2026 指引）
- 国内 A9 富豪多不自建完整家办，选**联合家族办公室（MFO）**几家共用专家团队降本

## 4. A9 = A10 裁剪（亿级小团队档）

A9 从 A10 完整建制中裁剪出「亿级 5-10 人小团队」：

**保留（8 部门 + 2 系统底座）**：

| 组 | 部门 | 对应 A10 岗位 |
|---|---|---|
| 财富幕僚组 | 幕僚长 | 家办 CEO/大秘（总协调、对外总窗口）|
| | 投资 | 投资经理 + 行业研究（投研，一二级/证券/股权）|
| | 财务 | 专职会计（家族账户/流水/对账/内部报表）|
| | 律师 | 专职律师（股权/合同/婚姻家事/纠纷/合规）|
| | 税务 | 税务顾问（国内筹划/跨境税务/信托架构）|
| 生活贴身组 | 秘书 | 私人助理（个人行程/差旅/人脉维护/邀约）|
| | 管家 | 家庭管家（多套房产运维/家政人员/物资采购）|
| | 保镖 | 安保保镖（人身风险评估/出行安防/舆情预警）|
| 底座系统 | 资产防火墙 | 信托/持股/保险/家企隔离架构 |
| | 人脉资源池 | 顾问/圈层/合作方通讯录 |

**A10 有、A9 暂缓**：医疗健康、教育传承、外联资源、资产运维、公益慈善、独立 CIO/CFO/COO、投研团队、信托/传承经理、风控合规独立岗、礼宾/艺术/旅行、技术总监专职岗。

> 说明：A9 里「IT」为 chuan-os 系统自身能力底座（写码/运维/网络/硬件），不算富豪编制；「研究」并入投资（投研）。删除的部门：新媒体/自由职业/学习/陪伴/社交/社交学习（A10 模型无对应，其中社交职责并入外联/人脉池待 A10 版评估）。
