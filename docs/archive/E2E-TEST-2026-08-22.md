## 2. 实测 1：研究岗位调研（web search 上线前后对比）

### 2.1 上线前（暴露问题）

CLI 实测指令：`帮我调研一下 XX 市场的竞品，同时查一下相关法规，最后汇总成报告`

| 子任务 | 模型实际输出 | 问题 |
|---|---|---|
| s1 调研竞品 | `list_dir(".")` | 把工具调用文本当答复 |
| s2 查法规 | 「很抱歉，我无法直接查询…建议您自行搜索」 | 无 web 工具，能力边界拒答 |
| s3 汇总 | 贴原始 JSON `{"return_code": 0, ...}` | 把工具返回值当正文 |

**根因分析**：
- 子任务跑在独立 checkpointer thread（无对话历史），裸任务提示让免费模型退化成贴工具原文
- 提示词的「输出要求」对免费模型是**软约束**，glm-4-flash 照样无视

**修复**：
- 子任务提示升级为结构化上下文（总任务背景 + 输出要求 + 禁止贴工具原文）— [role.py `_subtask_prompt`](file:///d:/Dev/Active/chuan-os/chuan/role.py#L360-L385)
- 新增**确定性退化检测** `_is_degenerate`：整段工具调用文本 / 原始 JSON 壳 / 空输出 → 标记失败，不拿垃圾当正文 — [role.py](file:///d:/Dev/Active/chuan-os/chuan/role.py#L476-L502)

### 2.2 上线后（web search + qwen-flash）

CLI 实测指令：`调研一下 2025 年中国新能源汽车市场的主要竞品和销量排名`

```
[研究] 拆分为 3 个子任务（2 波并行）
├─ 子任务 s1：收集竞品信息          ✓
├─ 子任务 s2：分析销量数据          ✓
├─ 子任务 s3：整理排名              ✓
```

**回复节选**（真实联网数据）：

> 比亚迪 347 万辆第一、吉利 149 万第二、长安 76 万第三…（2025 年新能源汽车销量）

**结论**：研究岗位从「瞎调 list_dir + 拒答」变为「真实调研 + 真实数据」，闭环打通。

## 3. 实测 2：大脑切换 qwen-flash

配置变更：`routing.default_brain: cloud_general → bailian_flash`，14 个 persona 删除硬编码 `brain: cloud_general`（改为跟随 default_brain，一处配置全局切脑）。

验证命令：

```python
from chuan.persona_loader import PersonaLoader
from chuan.brains import BrainRegistry
loader = PersonaLoader()
print(loader.get_persona('researcher').brain)  # → None（跟随默认）
print(loader.brains.default().name)            # → bailian_flash
```

CLI 实测：`武汉明天适合穿什么`

> [幕僚长] …根据我之前获取的信息，武汉今天的天气是晴朗的，温度为28°C，湿度为76%…

**观察**：答复引用了**之前会话**查过的武汉天气数据 —— 跨会话记忆（AsyncSqliteSaver 持久化）在真实对话中生效，不止是记忆模块的单测通过。

**结论**：qwen-flash 工具调用显著更稳（本阶段 3 轮实测全部一次通过，此前 glm-4-flash 偶发失败需重跑）。

## 4. 实测 3：团队协作三件套（借鉴 dsh-agent-teams）

### 4.1 验证脚本

```python
from chuan.runtime_supervisor import RuntimeSupervisor
from chuan import team_bus

s = RuntimeSupervisor(); s.wake_up()
roles = team_bus.available_roles()          # → 14 岗位注册
tools = s.tool_registry.get_tools(deny=[...])
any(t.name == 'ask_role' for t in tools)    # → True
r = await team_bus._ask_role_async('研究', '用一句话解释什么是量子纠缠')
s.shutdown()
```

### 4.2 结果

| 验证点 | 结果 |
|---|---|
| 角色总线注册 | ✅ 14 岗位（英文名 + 中文显示名双索引） |
| ask_role 工具挂载 | ✅ 全员可见 |
| 岗位间协作 | ✅ `ask_role('研究', …)` 返回真实答复（quantum entanglement …） |
| 异常隔离 | ✅ `ask_role('管家', '武汉天气')` 时 weather MCP 外部 API 超时 620s，链路返回干净 `[ERROR] 岗位「管家」协作失败` 而非崩溃 |
| 协作会话隔离 | ✅ 走独立 `ask:{role}` thread，不污染用户主会话历史 |
| 团队状态落盘 | ✅ data/teams/ 档案含角色/任务/子任务状态/attempts/结果摘要，终态 finished |
